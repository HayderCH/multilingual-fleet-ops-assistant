# Security and responsible disclosure

This repository contains only synthetic fleet records. Do not submit real vehicle locations, credentials or client data to the demo.

The service demonstrates three defensive patterns:

1. allowlisted intent-to-operation mapping;
2. clarification instead of guessing a missing vehicle;
3. explicit confirmation before simulated state-changing actions.

If you identify a security issue, report it privately through the contact information in Hayder Chakroun's GitHub profile rather than opening a public issue containing exploit details.
